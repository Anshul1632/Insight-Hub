# InsightHub

InsightHub is a full-stack data analysis platform that allows users to upload datasets, clean and preprocess data, perform exploratory data analysis (EDA), visualize results, and generate AI-powered insights through an interactive dashboard.

## Features

* Upload CSV and Excel datasets
* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Interactive visualizations
* AI-powered insights
* Responsive user interface

## Tech Stack

**Frontend:** React, Vite, JavaScript

**Backend:** FastAPI, Python, Pandas, NumPy, SQLite


## Getting Started

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
